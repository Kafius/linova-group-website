## Replacing these

These are stand-ins. The art direction for the real shot lives on each vertical
as `heroPhoto.subject` in `src/data/industries.ts`. Drop a replacement at the
same filename, update `heroPhoto.alt` to describe the new picture, and delete
that row above.
